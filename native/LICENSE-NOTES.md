# Лицензирование FLICKER VPN — разбор по компонентам

## Коротко

| Компонент | Лицензия | Основание |
|---|---|---|
| Расширение Firefox (JS: background/popup/options/lib) | проприетарный код автора (source-available в этом репозитории) | не линкуется с GPL-кодом: общается с native host через NM-протокол (JSON по stdio) — это агрегация через коммуникационный канал, а не производное произведение |
| `native/flicker-host` (Go-бинарник) | **GPL-3.0** | статически линкуется с sing-box (GPL-3.0) — производное произведение |
| sing-box v1.14.2 (движок TCP/443) | GPL-3.0 | upstream |
| hysteria core/extras (запасной HY2) | MPL-2.0 | файлово-совместимо с GPL при агрегации в бинарник GPL |
| metacubex/utls, refraction utls | BSD-3 | совместимы с GPL |
| sagernet/wireguard-go, gvisor netstack | MIT / Apache-2.0, BSD | совместимы с GPL |

## Что это значит на практике

1. **Бинарник `flicker-host` распространяется только под GPL-3.0** вместе с
   полными соответствующими исходниками (этот репозиторий их содержит) и текстом
   лицензии (`native/COPYING`).
2. **Основная модель поставки — сборка из исходников пользователем**
   (`native/install.sh` / `install.ps1` выполняют `go build` локально). В этом
   случае распространения бинарника не происходит вовсе и обязательства GPL
   не возникают ни у кого.
3. **Пакет `.xpi` GPL-кода не содержит** (только JS расширения) — его лицензия
   не затронута sing-box.
4. Если вы форкаете и распространяете `flicker-host` — сохраните GPL-3.0 для
   бинарника и приложите исходники; JS-часть расширения остаётся на условиях
   её автора.

## Заголовки в исходниках

Файлы Go, входящие в производное от sing-box произведение, несут SPDX-заголовок
`GPL-3.0-or-later` (см. `native/internal/singreg`, `native/internal/tunnel/sing.go`,
`native/cmd/flicker-host`). Остальные Go-пакеты (probe, nm, socks5, config,
tunnel/hy2) написаны автором проекта и линкуются в тот же бинарник — на них
распространяется та же GPL-3.0 как на часть составного произведения;
авторское право на исходный текст принадлежит автору проекта.
